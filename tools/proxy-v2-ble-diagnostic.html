Puffco New Proxy (2025) — BLE Diagnostic

  1. Wake the Proxy (press its button so the light is on) and keep it next to this computer.
  2. Serve this file over http://localhost — Web Bluetooth refuses file://. In this folder run
    python3 -m http.server 8000
    then open http://localhost:8000/proxy-v2-ble-diagnostic.html in Chrome or Edge (desktop).
  3. Click 1 · Scan & connect, pick the Proxy in the chooser. On Windows, accept the system pairing dialog if one appears.
  4. Click 2 · Run diagnostic. Everything below is read-only — it never writes to the device.
  5. Click 3 · Copy report and paste the text back to Muse.
